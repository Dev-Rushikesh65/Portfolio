## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v16 or above)
- [Git](https://git-scm.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/Dev-Rushikesh65/portfolio-.git

# Navigate into the project directory
cd portfolio-

# Install dependencies
npm install

# Start the development server
npm start
```

The app will run at `http://localhost:3000`.

---

## 📦 Build for Production

```bash
npm run build
```

The optimized build will be in the `build/` folder, ready for deployment.

---

## 🌍 Deployment

This portfolio is deployed on **Netlify**.

To deploy your own version:
1. Fork this repository
2. Connect the repo to your [Netlify](https://netlify.com) account
3. Set build command: `npm run build`
4. Set publish directory: `build`
5. Click **Deploy**
